# Mapa ORA Salamanca (Eurostars Las Claras)

Mapa móvil Leaflet centrado en el hotel, con capas oficiales **Zona A / Zona B** del Ayto. de Salamanca.

## Importante
El GeoJSON oficial `t02_zona_ora_actual` **no distingue plazas verdes vs azules**; solo polígonos de zona A/B.
La lista de calles verdes del panel es orientación práctica (ampliación jul 2026 / entorno hotel).

## Uso
Abre `index.html` en el móvil (Safari/Chrome). Necesita red para teselas OSM.

Fuente: https://opendata.aytosalamanca.es/datosabiertos/catalogo/dataset/zona-ora
